# Stone Works PDX

Stone Works PDX - local contractor for stone and bricks works - [https://stoneworkspdx.vercel.com](https://stoneworkspdx.vercel.com/?utm_source=github&utm_medium=readme)

## Installation & control

```sh
npm i
```

## Dev-mode

```sh
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.


## Tech Stack

- React
- Redux Toolkit
- React-router (data router) + SSR
- Tailwind CSS
- Radix-UI
- Lucide (Icons for React)
- Vite

## Performance and images

Run `npm run images:generate` after updating source photos, and commit the generated WebP files. See [performance notes](docs/performance.md) for measurements and validation.
